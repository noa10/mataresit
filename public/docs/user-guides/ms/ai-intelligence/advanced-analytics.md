# Panduan Analisis Lanjutan

## 📊 Buka Kecerdasan Perniagaan daripada Resit Anda

Analisis lanjutan dalam Mataresit mengubah data resit anda menjadi pandangan perniagaan yang boleh diambil tindakan. Temui corak perbelanjaan, optimumkan kos, dan buat keputusan berasaskan data dengan alat visualisasi dan pelaporan yang berkuasa.

### Ciri Analisis Mengikut Pelan

**Peringkat Percuma**
- Ringkasan perbelanjaan asas
- Pecahan kategori ringkas
- Carta gambaran keseluruhan bulanan
- Pilihan eksport standard

**Peringkat Pro**
- Analisis trend lanjutan
- Pelaporan perbandingan
- Julat tarikh tersuai
- Visualisasi dipertingkat

**Peringkat Max**
- Analisis ramalan
- Papan pemuka kecerdasan perniagaan
- Penjejakan KPI tersuai
- Format eksport lanjutan

## Langkah 1: Gambaran Keseluruhan Papan Pemuka Analisis

### Komponen Papan Pemuka Utama

**Petunjuk Prestasi Utama (KPI)**
- Jumlah perbelanjaan bulanan
- Nilai transaksi purata
- Kadar ketepatan pemprosesan
- Taburan kategori
- Penunjuk trend perbelanjaan

**Analisis Visual**
- Carta perbelanjaan interaktif
- Carta pai kategori
- Graf trend siri masa
- Carta bar perbandingan
- Visualisasi peta haba

### Penyesuaian Papan Pemuka

**Konfigurasi Widget**
- Tambah/buang widget analisis
- Ubah saiz dan kedudukan elemen
- Tetapkan tempoh masa lalai
- Konfigurasi selang muat semula

**Keutamaan Peribadi**
- Skema warna carta
- Format paparan mata wang
- Lalai julat tarikh
- Tetapan pemberitahuan
