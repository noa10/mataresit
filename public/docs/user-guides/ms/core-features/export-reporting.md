# Panduan Eksport & Pelaporan

## 📊 Hasilkan Laporan dan Eksport Data

Ubah data resit anda menjadi laporan profesional dan format eksport untuk perakaunan, penyediaan cukai dan analisis perniagaan.

---

## Jenis Laporan

### Laporan Ringkasan Perbelanjaan

**Laporan Bulanan:**
- Jumlah perbelanjaan mengikut bulan
- Pecahan kategori
- Analisis peniaga
- Perbandingan trend

**Laporan Suku Tahunan:**
- Ringkasan perbelanjaan suku tahunan
- Perbandingan tahun ke tahun
- Analisis belanjawan vs. sebenar
- Corak perbelanjaan bermusim

**Laporan Tahunan:**
- Gambaran keseluruhan tahunan lengkap
- Ringkasan sedia cukai
- Laporan perbelanjaan perniagaan
- Analisis perbelanjaan peribadi

### Analisis Kategori

**Perbelanjaan Mengikut Kategori:**
- Pecahan kategori terperinci
- Analisis subkategori
- Analisis trend kategori
- Laporan peruntukan belanjawan

**Analisis Peniaga:**
- Peniaga teratas mengikut perbelanjaan
- Laporan kekerapan peniaga
- Analisis purata transaksi
- Pengenalpastian peniaga baharu

## Format Eksport

### Laporan PDF

**Laporan Profesional:**
- Format ringkasan eksekutif
- Carta dan visualisasi
- Lampiran imej resit
- Pengepala laporan berjenama

**Laporan Cukai:**
- Format mematuhi IRS/LHDN
- Ringkasan perbelanjaan boleh potong
- Dokumentasi sokongan
- Susunan sedia audit

**Ciri:**
- Carta berkualiti tinggi
- Imej kecil resit
- Senarai transaksi terperinci
- Statistik ringkasan

### Eksport Excel/CSV

**Format Data:**
- Data transaksi mentah
- Sedia jadual pangsi
- Format mesra formula
- Sokongan berbilang lembar kerja

**Penyesuaian:**
- Pemilihan lajur
- Penapisan julat tarikh
- Pengelompokan kategori
- Pengiraan tersuai

**Kegunaan:**
- Import perisian perakaunan
- Analisis data lanjutan
- Penciptaan laporan tersuai
- Integrasi pangkalan data

### Eksport JSON/API

**Data Berstruktur:**
- Format boleh dibaca mesin
- Struktur serasi API
- Hubungan data bersarang
- Kemasukan metadata

**Sokongan Integrasi:**
- Import sistem ERP
- Suapan aplikasi tersuai
- Aliran kerja automatik
- Segerak data masa nyata

## Penapisan Data

### Pemilihan Julat Tarikh

**Julat Pratetap:**
- 7 hari lepas
- 30 hari lepas
- Bulan ini
- Bulan lepas
- Suku tahun ini
- Tahun ini
- Julat tersuai

**Sokongan Tahun Fiskal:**
- Tetapan tahun fiskal tersuai
- Tempoh pelaporan suku tahunan
- Penjajaran tahun cukai
- Perbandingan berbilang tahun

### Penapisan Kategori

**Sertakan/Kecualikan:**
- Pilih kategori tertentu
- Kecualikan perbelanjaan peribadi
- Fokus pada perbelanjaan perniagaan
- Hanya boleh potong cukai

**Penapisan Berhierarki:**
- Kategori utama
- Subkategori
- Pengelompokan tersuai
- Penapisan berdasarkan tag

### Penapis Lanjutan

**Penapis Jumlah:**
- Jumlah minimum/maksimum
- Julat jumlah
- Transaksi bernilai tinggi
- Ambang perbelanjaan

**Penapis Peniaga:**
- Peniaga tertentu
- Jenis peniaga
- Penapisan berdasarkan lokasi
- Pengelompokan vendor
